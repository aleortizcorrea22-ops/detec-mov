        📘 Guía: cómo dar de alta un sistema nuevo
        
    
          
    1. Crear el bot de Telegram
    
          
      
            
    1. Buscá @BotFather en Telegram y escribile /newbot.
      2. 
            
    2. Elegí un nombre (ej. "DETEC MOV Familia Pérez") y un usuario que termine en bot.
      3. 
            
    3. Te da un mensaje con el token (debajo de "Use this token..."). Copialo.
      4. 
          
    
          
    Un bot nuevo por cada familia, nunca reutilices uno.
    

          
    2. Crear el grupo
    
          
      
            
    1. Creá un grupo nuevo en Telegram y agregale el bot.
      2. 
            
    2. Agregate vos también.
      3. 
            
    3. Mandá /start@usuario_del_bot en el grupo (hace falta para que el bot "vea" el grupo).
      4. 
          
    

          
    3. Conseguir el chat_id
    
          
    Lo más fácil: pegá el token en cualquier celular con la app abierta (sección Telegram) y tocá "Buscar mi chat_id". El del grupo empieza con -100.
    

          
    4. Dar de alta el sistema acá abajo
    
          
    En "Dar de alta un sistema nuevo": ID = el chat_id, Nombre = como quieras identificarlo, Usuario del bot y Token = del paso 1, Días = cuánto dura el permiso.
    

          
    5. Mandar el manual a la familia
    
          
    Desde tu PC, abrí manual-detec-mov.html, pegá el token y chat_id en el recuadro violeta, y descargá la copia lista para enviar por Telegram o WhatsApp.
    

          
    6. Probar
    
          
    Pedile a la familia que toque "Enviar alerta de prueba" y confirmá que te llegue al grupo.
